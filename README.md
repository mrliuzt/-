# 智能密码锁 (Smart Lock)

基于 STM32F103 的多功能智能密码锁系统，支持密码、IC卡、指纹三种解锁方式。

## 功能特性

### 解锁方式
| 方式 | 说明 |
|------|------|
| **密码解锁** | 4x4矩阵键盘输入，最长9位密码 |
| **IC卡解锁** | RCC522射频识别，支持M1卡 |
| **指纹解锁** | AS608光学指纹模块，录入简单 |

### 安全机制
- 密码输入显示为 `*` 保护隐私
- 连续密码错误会触发警告
- 错误10次触发SOS蜂鸣器报警
- 15秒无操作自动锁定

### 管理员功能
- 按 `#` 进入管理员模式（需指纹验证）
- 录入新指纹
- 录入新IC卡
- 修改用户密码

## 硬件架构

```
STM32F103C8T6
├── 4x4 矩阵键盘    (GPIO矩阵扫描)
├── OLED显示屏      (I2C/SPI)
├── RCC522读卡器    (SPI接口)
├── AS608指纹模块   (USART)
├── 蜂鸣器          (PWM)
├── 继电器控制      (开门)
└── RTC时钟        (掉电保持)
```

## 技术栈

- **微控制器**: STM32F103 (ARM Cortex-M3)
- **开发环境**: Keil MDK
- **固件库**: STM32F10x Standard Peripheral Library
- **通信协议**: SPI、I2C、USART、GPIO

## 使用说明

### 用户模式
1. 系统上电后进入用户模式，显示时钟
2. 输入密码后按 `#` 确认
3. 密码正确则开门3秒
4. 可用IC卡或已录入指纹解锁

### 管理员模式
1. 按键盘 `#` 进入管理员验证
2. 放置已录入的手指进行指纹验证
3. 验证通过后进入管理菜单
4. 可选操作：
   - `1` - 一键开锁
   - `2` - 录入指纹
   - `3` - 录入IC卡
   - `*` - 修改密码
